# Letter.For.You

A quiet, cinematic digital book containing a personal letter.

Open the book. Read slowly. Turn the pages by tapping the right side of the book (or the left side to go back).

## View it

**Live experience:**  
Once GitHub Pages is enabled, the letter will be available at:  
**https://kevinmatangong-eng.github.io/Letter.For.You/**

### How to enable GitHub Pages (takes 30 seconds)
1. Go to the repository: https://github.com/kevinmatangong-eng/Letter.For.You
2. Click **Settings** → **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose branch **main** and folder **/ (root)**
5. Click **Save**

The site will be live within a minute or two.

You can also simply open `index.html` directly in any modern browser.
